## Marco normativo

- **NCh-ISO 27001:2022** — Sistema de Gestión de Seguridad de la Información (SGSI)
- **Ley 21.663** — Marco de Ciberseguridad (obliga a instituciones públicas a crear gobernanza de ciberseguridad)
- **Ley 21.719** — Protección de Datos Personales (aplica a todo el sector salud)
